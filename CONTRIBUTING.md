# Contributing

Thank you for helping improve Karaoke Media Manager.

1. Fork the repository and create a focused branch.
2. Do not commit media, lyrics, model weights, cookies, databases, local paths,
   or credentials.
3. Install the application with `./install.ps1`, or follow the manual setup in
   the README.
4. Run `python -m pytest` from `backend`, then `npm test` and `npm run build`
   from `frontend`.
5. Open a pull request describing the creator workflow affected and the tests
   performed.

Use GitHub's private vulnerability reporting flow for security issues rather
than a public issue. By contributing, you agree that your contribution is
licensed under the repository's MIT licence.
